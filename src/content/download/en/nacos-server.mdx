# Nacos Server Download
:::tip
Nacos Server **3.3.0** is now available, with protocol-neutral Agent management and RAD discovery, ARD resource search, MCP lifecycle management, optional DNS discovery, dynamic plugin management, and client authentication enabled by default. **2.5.5** remains the recommended 2.x release with Java 8 compatibility.

Feel free to [download and try it out](#stable-versions).

:::
## System Requirements
:::note
The following are the minimum system requirements for deploying Nacos Server. If your environment does not meet the minimum requirements, it may cause the Nacos Server to be unable to deploy and start.
:::
|             |                                                                                                                         |
|-------------|------------------------------------------------------------------------------------------------------------------------------------|
| **JDK/JRE** | 3.x: 17 and above; 2.x: 8 and above  |
| **CPU**  | 1 core or higher, 64-bit CPU support    |
| **Memory** | 2G or more |
| **Hard disk** | No minimum requirement, adjust according to log retention |
| **Operating system** | Linux, Mac OS X, Windows |

## One-Click Installation (Recommended)

[nacos-setup](https://github.com/nacos-group/nacos-setup) provides one-click automated deployment, handling download, auth configuration, port detection and Java environment validation automatically.

<Tabs>
  <TabItem label="Linux/macOS">
    ```bash
    curl -fsSL https://nacos.io/nacos-installer.sh | sudo bash
    ```
  </TabItem>
  <TabItem label="Windows (PowerShell)">
    ```powershell
    powershell -NoProfile -ExecutionPolicy Bypass -Command "iwr -UseBasicParsing https://nacos.io/nacos-installer.ps1 | iex"
    ```
  </TabItem>
</Tabs>

Nacos will be automatically deployed after installation. For more usage, refer to [Deploy with nacos-setup](/docs/latest/manual/admin/deployment/deployment-nacos-setup/).
