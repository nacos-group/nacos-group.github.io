# Nacos Server 下载

:::tip

Nacos Server **3.2.3** 和 **2.5.3** 已发布。3.2.3 聚焦 AI Registry、Skill、MCP 与新版控制台体验改进，并修复 Config 命名空间隔离、Naming 校验和客户端稳定性问题；2.5.3 在保持 JDK 8 基线的同时带来兼容安全依赖升级、客户端稳定性和服务端请求校验改进。

欢迎[下载和试用](#稳定版本)。

:::


## 系统要求

:::note

以下是部署Nacos Server的最小系统要求。如果您的环境无法满足系统最小要求，可能会导致无法部署和启动Nacos Server。

:::

|             |                                                                                                                         |
|-------------|------------------------------------------------------------------------------------------------------------------------------------|
| **JDK/JRE** | 17及以上  |
| **CPU**  | 1核及以上，支持64位CPU    |
| **内存** | 2G及以上 |
| **硬盘** | 无最小要求，根据保留日志自行调整|
| **操作系统** | Linux, Mac OS X, Windows |

## 一键安装（推荐）

[nacos-setup](https://github.com/nacos-group/nacos-setup) 提供一键自动化部署，自动处理下载、鉴权配置、端口检测和 Java 环境验证等操作。

<Tabs>
  <TabItem label="Linux/macOS">
    ```bash
    curl -fsSL https://nacos.io/nacos-installer.sh | sudo bash
    ```
  </TabItem>
  <TabItem label="Windows（PowerShell）">
    ```powershell
    powershell -NoProfile -ExecutionPolicy Bypass -Command "iwr -UseBasicParsing https://nacos.io/nacos-installer.ps1 | iex"
    ```
  </TabItem>
</Tabs>

安装完成后将自动部署 Nacos 服务。更多用法请参考[使用 nacos-setup 一键部署](/docs/latest/manual/admin/deployment/deployment-nacos-setup/)。
