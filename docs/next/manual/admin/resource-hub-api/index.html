Hub 扩展接口参考

本页补充 Admin API 和 Console API 中的 Skill 接口，涵盖其余四类资源。以下管理 API 的源码起始版本为 3.3.0；部署构建必须实际包含 Hub 实现，不能据版本号认定已发布发行包包含开发分支功能。

1. 地址、身份与类型边界

Admin 示例基址为 http://127.0.0.1:8848，下表已包含默认 /nacos context；Console 基址为 http://127.0.0.1:8080，没有 /nacos 前缀。自定义 context 或代理时按部署调整。请求使用当前鉴权插件要求的身份；下文以 accessToken Header 为例。

以下是独立的固定路由，不接受 {resourceType} 占位参数。每行对应一个操作；同一操作在四类资源上的参数与返回类型相同，类型由路径确定。五类均支持导入，只有 Skill 有 /clone。本页四类资源没有 /copy 或 /clone，也没有专用的 /hub/.../list、detail、content、download 读接口。

2. 管理操作契约

POST 使用 application/x-www-form-urlencoded；GET 参数在 Query 中。ID 为正的 64 位整数；JSON 返回字符串，调用者不要转为 JavaScript number。下例 101、1 仅为示例，后续请求应使用实际返回的 ID 和最新 metaVersion。

2.1. 共享

需源资源 READ、WRITE 权限。源资源必须启用，指定版本已上线；MCP、Agent、AgentSpec 必须为 PUBLIC，Prompt 不增加 scope 要求。版本固定，不自动跟随 latest。

请求参数

参数名类型必填参数描述
sourceNamespaceIdstring是源 Namespace，不能为 Hub 保留 Namespace。
sourceNamestring是源资源实际名称；Prompt 为 promptKey。
sourceVersionstring是明确的已上线版本，不接受 latest。
expectedSourceResourceIdstring否预期源资源 ID，校验固定资源身份。

返回数据

参数名参数类型描述
dataHubShareResult共享操作结果。重复共享可返回 ALREADY_SHARED。

示例

共享其他类型时使用索引中的固定 URL 和对应源名称；字段不变。

2.2. 调整共享版本

需源 READ、WRITE，目标源版本满足共享条件。通过 expectedMetaVersion 执行 CAS，过期修订返回冲突；重新读取状态后再决定是否重试。

请求参数

参数名类型必填参数描述
hubEntryIdstring是对应类型的 Hub 条目 ID。
targetVersionstring是新的明确上线源版本，不是导入目标版本。
expectedMetaVersionstring是最近获取的条目修订号。

返回数据

参数名参数类型描述
dataHubShareResult新状态和修订号；结果可为 ADJUSTED 或 UNCHANGED。

示例

2.3. 取消共享

需源 WRITE。源已变为 private 或版本下线时，仍可由有权限者执行清理。不会删除源或已导入目标。

请求参数

参数名类型必填参数描述
hubEntryIdstring是对应类型的共享条目 ID。
expectedMetaVersionstring是最近读取的条目修订号。

返回数据

参数名参数类型描述
dataHubShareResultactive=false；结果可为 UNSHARED 或 ALREADY_UNSHARED。

示例

2.4. 强制下架

需独立的全局管理员治理权限；普通资源 ACL 不能替代管理员身份。操作记录下架原因并通过 CAS 检查。

请求参数

参数名类型必填参数描述
hubEntryIdstring是对应类型的共享条目 ID。
expectedMetaVersionstring是最近读取的条目修订号。
reasonstring是非空下架原因，最多 512 个字符。

返回数据

参数名参数类型描述
dataHubShareResult下架结果；active=false。

示例

2.5. 查询源共享状态

虽然为 GET，仍需源 WRITE；不是公开目录接口，也不要求源当前仍可共享。源资源存在但未共享时 data=null。

请求参数

参数名类型必填参数描述
sourceNamespaceIdstring是源 Namespace。
sourceNamestring是源资源实际名称。

返回数据

参数名参数类型描述
dataHubResourceShareState精简状态或 null。

示例

2.6. 查询治理状态

需全局管理员治理权限，不因调用者拥有 Hub READ 或某个普通资源 ACL 而开放。

请求参数

参数名类型必填参数描述
hubEntryIdstring是对应类型的 Hub 条目 ID。

返回数据

参数名参数类型描述
dataHubResourceShareState包含用于治理 CAS 的修订号，不返回数据库或文件存储信息。

示例

2.7. 从 Hub 导入

需合法 Hub 读取权限与目标 Namespace WRITE，不要求源 Namespace READ。创建独立 PRIVATE 草稿，不自动审核、上线或同步。目标同名、版本或依赖冲突时不覆盖已有资源。

请求参数

参数名类型必填参数描述
hubEntryIdstring是固定共享条目 ID；路径确定资源类型。
targetNamespaceIdstring是有写权限的业务 Namespace，不能为保留 Hub Namespace。
targetNamestring是符合该类型命名规则的新名称。
targetVersionstring否草稿版本，默认 0.0.1，不接受 latest。
mcpRemoteServerConfigstring否仅 MCP；McpServerRemoteServiceConfig 的 JSON 字符串，最多 65536 字符。通常省略；如传入必须与固定源配置一致，不能用它覆盖或重绑连接。其他三类禁止设置此字段。

不能同时传入 sourceNamespaceId、sourceName 或 sourceVersion，即使其值为空也不能作为第二套来源选择器。

返回数据

参数名参数类型描述
dataHubResourceTransferResult目标草稿与来源信息。

示例

MCP STDIO 不创建 Naming 服务；普通 REF 保留源引用；源自有 Direct 从唯一、合法的持久固定地址创建目标自有服务。目标服务已存在时冲突，失败回滚的目标是清理本次导入创建的资源。清理失败时，参见重试说明。删除目标不删除源或 REF 服务；源撤销不删除已导入目标。Agent 导入不复制动态运行时注册。

3. 响应模型

成功 JSON 使用 Result<T>，根层级为 code、message、data，不是 data.data。管理响应仅供已授权调用者；不要把来源身份字段直接公开到目录。

3.1. HubShareResult

参数名参数类型描述
dataHubShareResult共享生命周期操作结果。
data.hubEntryIdstring共享条目 ID。
data.displayNamestring展示名称，不作为读取身份。
data.sourceNamespaceIdstring授权管理操作涉及的源 Namespace。
data.sourceResourceIdstring固定源资源 ID。
data.sourceNamestring源资源名称。
data.sourceVersionIdstring固定源版本 ID。
data.sourceVersionstring固定源版本。
data.metaVersionstring后续写操作的 CAS 修订号。
data.outcomeHubShareOutcomeCREATED、ALREADY_SHARED、REACTIVATED、ADJUSTED、UNCHANGED、UNSHARED、ALREADY_UNSHARED、FORCE_UNSHARED。
data.activeboolean当前共享是否启用。

3.2. HubResourceShareState

参数名参数类型描述
dataHubResourceShareState源写权限或管理员授权后的状态；可为 null。
data.hubEntryIdstring共享条目 ID。
data.metaVersionstringCAS 修订号。
data.sharedVersionstring当前明确共享版本。
data.activeboolean启用状态。

3.3. HubResourceTransferResult

参数名参数类型描述
dataHubResourceTransferResult独立目标草稿。
data.targetNamespaceIdstring目标 Namespace。
data.targetNamestring目标名称。
data.draftVersionstring新草稿版本。
data.statusstringdraft。
data.originstring本页四类导入为 HUB。
data.targetResourceIdstring目标资源 ID。
data.hubEntryIdstring固定来源的共享条目 ID。
data.resourceTypestringmcp、agent、prompt 或 agentspec。

4. 通过原有资源接口读取

以下均为 GET，并须传 namespaceId=__nacos_ai_hub__。Admin 路径加部署的 /nacos context；Console 路径使用 Console 端口。筛选、分页和响应沿用该资源既有接口，不能把五类模型统一替换为自定义 Hub 内容 DTO。

类型Admin / Console 已有资源路径Client 已有路径身份参数
MCP/v3/admin/ai/mcp、/v3/console/ai/mcp，及各自 /list、/versions、/version/v3/client/ai/mcp/search、/v3/client/ai/mcpmcpName 为共享目录返回的不透明名称
Agent/v3/admin/ai/agents、/v3/console/ai/agents，及 /list、/versions、/version、/runtime-endpoints/v3/client/ai/agents/search、/v3/client/ai/agentsagentName 为不透明名称；运行时快照沿用 protocol
Prompt/v3/admin/ai/prompt、/v3/console/ai/prompt 的 /list、/governance、/versions、/version、/version/download；保留 /metadata、/detail 兼容读取/v3/client/ai/prompt/search、/v3/client/ai/promptpromptKey 为不透明名称；管理详情用 /governance
AgentSpec/v3/admin/ai/agentspecs、/v3/console/ai/agentspecs，及 /list、/version、/version/meta/v3/client/ai/agentspecs/search、/v3/client/ai/agentspecsAdmin/Console 为 agentSpecName，Client 为 name

读取须通过 Hub READ 和共享有效性检查，不额外要求源 READ。匿名访问取决于所选鉴权插件与匿名 AI 配置；PUBLIC 本身不绕过鉴权。资源身份和版本必须匹配当前共享引用，不得回退 latest。重复冲突的 Namespace 参数会被拒绝。共享被撤销、固定源版本下线、源被删除或停用后，内容不可读；除 Prompt 外，源改为 PRIVATE 也会撤销共享有效性。

四类管理/搜索模型中的 hub 元信息使用 HubResourceDiscoveryInfo，包含 hubEntryId、resourceType、展示字段 resourceName、固定 version、sourceDisplayName、author、downloadCount、updateTime 和 sourceReadable。sourceNamespaceId、sourceName 仅在独立的源 READ 与可见性检查通过后返回；不能要求调用者先有源权限才能读 Hub。

同名共享条目的 hub.resourceName 可以相同，该字段展示源资源名称。读取时将所选条目的 hub.hubEntryId 或列表返回的对应不透明标识传给该类型的名称参数，指定版本时传 hub.version。

Client Agent 保持 AgentDiscoveryResult，AgentSpec 保持 AgentSpec，不要求内容响应具有顶层 hub。MCP 保持原详情结构，Prompt 保持原模板 DTO。不能用响应缺少 hub 判断所有 Client 读取失败。普通 Namespace 的读取语义不变。

5. 关闭能力与异常

nacos.ai.hub.enabled=false 时，在完成身份和参数检查后，共享目录返回空页，Hub 内容和七类管理操作返回 HTTP 501 / API_FUNCTION_DISABLED（40001）。Skill 直接克隆不受此开关影响。

参数非法通常为 HTTP 400 / PARAMETER_VALIDATE_ERROR（20002）；权限拒绝为 403，CAS、同名或服务依赖冲突为 409。不存在或失效资源按照各资源接口的既有错误模型返回，不能假定所有类型的业务错误码相同。来源存储系统故障应返回脱敏 5xx，不能伪装为空目录。错误结果与成功结果应分开处理。

5.1. 导入或克隆失败后重试

Hub 导入或 Skill 跨命名空间克隆失败后，如果清理也未完成，服务端会保留目标名称的占位记录和恢复信息。此时编辑或删除目标资源，或在同一命名空间使用相同目标名称重试，都可能返回 HTTP 409。请等管理员检查目标草稿及相关依赖资源、确认清理完成后再重试。
